# Contributing

## Adding Preferences

Edit `src/data/preferences.ts` and add entries to the appropriate category.

## Adding CSS Options

Edit `src/data/cssOptions.ts` to add userChrome.css or userContent.css options.

## Updating Presets

Edit `src/data/presets.ts` to modify preset configurations.

## Project Structure

```
src/
├── App.tsx              # Main app
├── components/          # UI components
├── data/                # Preferences, CSS options, presets
├── hooks/               # Custom hooks
└── utils/               # Generators
```
