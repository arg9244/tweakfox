# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024

### Added
- Initial release
- 100+ preferences from Betterfox and arkenfox/user.js
- 6 categories: Performance, Security & Privacy, Telemetry & Data, UI & Annoyances, Privacy Hardening, Security Hardening
- 4 presets: Balanced, Privacy Focused, Performance, Hardened
- Catppuccin Mocha theme
- Animated UI with Framer Motion
- Search functionality
- Live preview of generated user.js
- Download and copy to clipboard
- Risk level indicators (Low/Medium/High)
- Source attribution (Betterfox/arkenfox/Both)
- Technical details expandable section
- Responsive design
- GitHub Pages deployment workflow
- MIT License
- README, CONTRIBUTING, and project documentation
